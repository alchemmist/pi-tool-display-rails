# pi-tool-display-rails

A Pi coding-agent display extension based on `@estebanforge/pi-tool-display`.

It keeps the compact tool cards and Markdown-aware user-message rendering, but replaces the bordered `user` box with a single colored left rail. The rail uses the active Pi theme and does not paint a background, so it follows terminal light and dark themes.

Install with:

```text
pi install git:github.com/alchemmist/pi-tool-display-rails
```

The extension keeps the upstream `/tool-display` settings and configuration format.
